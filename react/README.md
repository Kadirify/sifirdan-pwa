# react

`html/` klasöründeki alışveriş listesinin create-react-app ile yazılmış hali.
Anlatım için [docs/05-react-ile-pwa.md](../docs/05-react-ile-pwa.md).

```
npm install
npm start          # geliştirme, service worker kapalı
npm run build
npx serve -s build # çevrimdışı davranışı burada görülüyor
```

Node 16 ile yazıldı.
